# Os Pets da Inês

Site (PT/EN) for a solo pet-sitter in Barcarena, Portugal — pet boarding, pet sitting, and dog walking.

## Pages

PT is the default locale (no prefix), EN is prefixed `/en`, same slugs otherwise:

| Page | PT | EN |
|---|---|---|
| Home | `/` | `/en` |
| About | `/sobre` | `/en/about` |
| Services hub | `/servicos` | `/en/services` |
| Pricing | `/precario` | `/en/pricing` |
| Booking conditions | `/condicoes-reserva` | `/en/booking-conditions` |
| Contacts | `/contactos` | `/en/contact` |

## Pricing

A static comparison table plus an interactive calculator that estimates cost from service type, season, boarding stay length, dog count, and day/visit count.

## Content

Every string is available in both Portuguese and English. Service photos rotate randomly per browser session, so different visitors see variety while a single visit stays consistent.
